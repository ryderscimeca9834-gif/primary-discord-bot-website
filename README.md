## 🛠️ Setup Instructions

### Local Development

1. Clone the repository:
```bash
git clone https://github.com/ryderscimeca9834-gif/primary-discord-bot-website.git
cd primary-discord-bot-website
```

2. Open the files locally:
   - Simply open `index.html` in your web browser
   - Or use a local development server:
   ```bash
   python -m http.server 8000
   ```

### Deploy to GitHub Pages

1. Enable GitHub Pages in repository settings
2. Set the source branch to `main`
3. Your site will be available at `https://ryderscimeca9834-gif.github.io/primary-discord-bot-website`

### Deploy to Other Hosting

The website is static HTML/CSS and can be deployed to:
- Vercel
- Netlify
- Any static hosting service
- Your own web server

## ⚙️ Configuration

To customize the website, edit these values:

### In `index.html`:
- Replace `YOUR_BOT_ID` with your actual Discord bot ID in the invite link
- Update the Discord server link in the Support section
- Modify contact information as needed

### In `privacy-policy.html`:
- Update contact email addresses
- Modify Discord server invite link
- Adjust data retention periods as per your bot's actual policies
- Update company/bot information

### In `styles.css`:
- Modify color scheme by changing CSS variables in `:root`
- Adjust spacing and layout as needed
- Customize fonts and animations
